Detection guide

Why might BrowserTrust flag this?

01

Form followed by a request
A form submission followed by matching network activity can trigger a review finding. It does not prove the form values were transmitted.

02

Browser API activity
Selected API calls can be worth reviewing, but an observed call does not prove it succeeded.

03

Repeated POST requests
Several POST requests to the same cross-origin host in a short window may match a repetition rule. Repetition alone does not prove malicious intent.
