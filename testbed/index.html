What should BrowserTrust show?

It should show page activity and network observations. Depending on Chrome permissions and the extension's matching rules, it may also produce a review finding. A finding is a heuristic based on observed metadata, not proof of malicious intent or of what a request payload contained.

If a request fails, confirm the testbed server is running with npm run testbed and that the browser console is not reporting a connection or CORS error.
